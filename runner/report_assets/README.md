# Report assets

Logo IN Groupe: official unmodified asset from https://ingroupe.com/app/uploads/2022/04/logo-ingroupe.svg, rendered as a PNG for offline use. Brand reference: https://ingroupe.com/visual-identity/.

The icon masks are rasterized Material Design Icons from the qtawesome glyphs used in runner/ui/icons.py (Material Design Icons / Pictogrammers, Apache-2.0). They are embedded in the exported HTML; no font or network request is needed.
